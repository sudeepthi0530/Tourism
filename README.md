# 🌴 Namma Dakshina – Explore the Beauty of Dakshina Kannada

**Namma Dakshina** is a tourism website designed to showcase the natural beauty, cultural heritage, historical landmarks and spiritual destinations of Dakshina Kannada, Karnataka.

The platform helps visitors discover popular tourist destinations, explore local attractions and access useful travel information through an elegant and user-friendly interface.

---

## 🌟 Project Overview

Dakshina Kannada is known for its beautiful beaches, ancient temples, historical monuments, rich traditions and scenic natural landscapes.

Namma Dakshina aims to bring these attractions together on a single digital platform, making it easier for tourists to explore and learn about the region.

## ✨ Features

- **Explore Destinations:** Discover tourist attractions across Dakshina Kannada.
- **Beaches:** Explore popular coastal destinations such as Panambur, Tannirbhavi, Someshwar, Surathkal and Sasihithlu.
- **Temples:** Discover important religious destinations and their cultural significance.
- **Heritage:** Explore historical buildings, monuments, churches and cultural landmarks.
- **Nature & Parks:** Discover gardens, waterfalls, wildlife attractions and natural destinations.
- **Destination Details:** Individual pages featuring descriptions, experiences, visitor information and photo galleries.
- **Google Maps Integration:** Find destination locations through Google Maps links.
- **Responsive Design:** Designed to provide a user-friendly experience across different screen sizes.
- **Cultural Theme:** A traditional visual identity inspired by the art and heritage of Dakshina Kannada.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/sudeepthi0530/Tourism-.git
```

### 2. Navigate to the Project

```bash
cd Tourism-
```

### 3. Navigate to the Frontend

```bash
cd frontend
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start the Development Server

```bash
npm run dev
```

### 6. Open in Browser

Visit:

```text
http://localhost:3000
```

## 🎨 Design & User Experience

The website follows a traditional and elegant visual identity inspired by the cultural heritage of Dakshina Kannada.

**Design elements:**
- Deep Burgundy – `#27151F`
- Antique Gold – `#C6A16B`
- Warm Ivory – `#F3E9D9`
- Terracotta – `#A64F3C`
- Bell MT typography with serif fallbacks
